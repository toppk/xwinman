The Common Desktop Environment (CDE) is a commercial graphical user interface
for UNIX in its various flavors (AIX, Digital UNIX, HP/UX, Solaris, UnixWare,
etc.). The desktop has been jointly developed by Hewlett-Packard, IBM, Novell
and Sun Microsystems. It has been adopted as a standard operating environment
by these companies and many others in the UNIX workstation market.

The CDE incorporates the dtwm window manager. This is a Motif-compliant,
virtual window manager and is similar to the HP/UX program vue.
