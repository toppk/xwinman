Xfce is a lightweight desktop environment for UNIX platforms. It is similar to
the commercial CDE, and is now based on the GTK+ toolkit.

A strong point of Xfce is its ease of configuration - it is driven entirely by
the mouse. The latest version features drag and drop, session management,
translations for numerous languages, including support for multi-byte
character sets, and numerous other features.

The desktop environment includes a window manager, called XFwm, the main
panel, a file manager, a backdrop manager, a sound manager, a calendar, a
pager module, and a GNOME compliance module.
