## Icons & Textures

Many window managers allow the use of coloured icons as buttons and menu
items, and also pictures or textured backgrounds, all of which can
considerably improve the appearance of an X desktop. The following web pages
and programs can help in the management and display of icons and images.

- [The XPM Page:](http://www.inria.fr/koala/lehors/xpm.html) A description of
  this popular icon format, along with full documentation and the latest
  libary routines themselves.
- [XV:](http://www.trilon.com/xv/) The *essential* interactive image display
  program.
- [Xbmbrowser:](http://src.doc.ic.ac.uk/packages/X11-contrib/utilities/xbmbrowser5.1.tar.gz)
  A program to display and manage XPM collections.
- Xpmroot: A program for displaying XPM images in the background. It is
  available in the [fvwm](ftp://ftp.hpc.uh.edu/pub/fvwm) distribution.

Moving on to the images themselves, there are several collections available at
this site:

- [XPM icons](icons/) (Archive: [icons.tar.gz,](icons.tar.gz) 24K)
  (Image of [all icons](xpmicons.gif), 27K)
- [XPM textures](textures/) (Archive: [textures.tar.gz,](textures.tar.gz)
  188K)
- [GIF and JPEG textures](tiles/) (Archive: [tiles.zip,](tiles.zip) 3.9MB)

You may want to check out [Anthony's Icon
Library,](http://www.cit.gu.edu.au/~anthony/icons/) which contains a huge
collection of xpm icons and backgrounds.

Also of interest is a nice collection of [3d looking
pixmaps,](ftp://pc50.zrz.tu-berlin.de/pub/3dpixmaps/) which is also available
from [sunsite.unc.edu.](ftp://sunsite.unc.edu/pub/Linux/X11/icons/)
