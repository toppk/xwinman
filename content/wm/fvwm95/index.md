Fvwm95 is a hack based on fvwm2.x. It tries to emulate the good features of a
well known product without bloating the regular fvwm code.

It has all the functionality of fvwm2, but with a different look, and an extra
taskbar module.

Here are some configuration files for fvwm95, with screenshots. The
configuration files should be renamed to <kbd>.fvwm2rc95</kbd>.

{{< contributions 1 >}}

For more information and downloads see the [FVWM-95 home
page.](http://fvwm95.sourceforge.net)

Users of fvwm95 may be interested in
[Xaw95](http://www.netsw.org/x11/libs/xaw95/) which is a replacement for the
Athena Widget library to change the appearance of the numerous X programs
which use this library. It is based on the popular
[Xaw3d](ftp://ftp.x.org/contrib/widgets/Xaw3d/) library which gives standard
Athena widgets a 3D look.
