Blackbox is an original window manager, sharing no code with any others. It's
designed to be fairly small and minimal, making it particularly suited to less
powerful computers. It doesn't support images, other than generated gradients,
but it does support multiple desktops and is NetWM compliant, making it
compatible with KDE and GNOME.
